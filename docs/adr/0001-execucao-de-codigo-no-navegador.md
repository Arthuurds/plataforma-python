# Execução de código do estudante no navegador via Pyodide

Os desafios rodam o código Python do estudante no próprio navegador, compilado para WebAssembly com Pyodide, e não em um servidor com sandbox. Assim a resposta é imediata e não há custo de infraestrutura no MVP. A consequência aceita é que o gabarito dos testes fica visível ao estudante, então XP e conquistas não funcionam como prova de habilidade; se a integridade do progresso virar requisito, a execução deve ser reavaliada para o servidor.
